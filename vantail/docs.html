Quick start

Install the CLI, link a project and ship your first deploy. It takes about five minutes.

Before you start: you need a Vantail account (the free Hobby plan is fine) and a project in a git repository.

Install the CLI

The vantail command line tool runs on macOS, Linux and Windows. Pick the install method you prefer:

npm

shell
npm install --global vantail-cli

Shell script

shell
curl -fsSL https://get.vantail.example/install.sh | sh

Binary

Download the archive for your system from the releases page, unpack it and move vantail into a folder on your PATH.

Check that it worked, then sign in. The browser opens to confirm your account.

shell
vantail --version
vantail login

Configure your project

From the root of your repository, run vantail link. Vantail detects the project type and suggests a build command. Most projects need nothing else.

To override the defaults, add a vantail.toml file:

vantail.toml
[build]
command = "npm run build"
output  = "dist"

[preview]
private = true
Build options
Option Default Description
commanddetectedThe command that builds your project.
outputdetectedThe folder to serve after the build.
node22Runtime version used for the build.
privatefalseRequire sign-in to open preview links.

Environment variables

Add secrets with the CLI. Values are encrypted and can be scoped to production, preview or both.

shell
vantail env add DATABASE_URL --scope production

Never commit secrets. Keep .env files out of git and add values with vantail env instead.

Your first deploy

Run vantail deploy for a preview, or add --prod to go live. Once your repository is linked, every push to the main branch deploys automatically.

shell
vantail deploy --prod

Roll back a deploy

Every build is kept. To restore the previous one, run the command below, or press R on a deploy in the dashboard.

shell
vantail rollback

Single sign-on

On the Team plan, owners can require single sign-on from Settings → Security. Members then sign in through your identity provider, and new members join automatically.

Single sign-on is available on the Team plan.
