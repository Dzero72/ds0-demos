// how it works

Three commands to production

Install the CLI, link your repository and push. Vantail handles the rest.

  1. Step 01

    Install

    One global package, on macOS, Linux or Windows.

    shell
    npm i -g vantail-cli
  2. Step 02

    Link

    Connect a repository and pick a team. It takes ten seconds.

    shell
    vantail link
  3. Step 03

    Push

    Every push builds. The main branch goes live.

    shell
    git push origin main
// config

Zero config, until you want some

Vantail reads your project and picks the right build. When you need more control, a short vantail.toml covers it.

  • Static sites, servers and containers
  • Monorepos with per-folder builds
  • Custom build and output commands
Read the configuration docs

Static

vantail.toml
# A static site
[build]
command = "npm run build"
output  = "dist"

Server

vantail.toml
# A long-running server
[service]
start  = "node server.js"
port   = 3000
health = "/healthz"

Monorepo

vantail.toml
# One repository, two apps
[[app]]
name = "web"
root = "apps/web"

[[app]]
name = "api"
root = "apps/api"

What customers say

Questions, answered

More in the docs.

Do I need to change my code?

No. Vantail runs the same build command you run locally and serves the output. Most projects deploy without any changes.

What happens if a deploy fails?

Nothing changes for your visitors. The last good build keeps serving traffic, and you get the failing log in your terminal and inbox.

Can I use my own domain?

Yes, on every plan. Add the domain, point one DNS record at Vantail and certificates are issued automatically.
